# Proyek Inventaris Elektronik - Konsep Inheritance

Proyek ini dibuat untuk memenuhi tugas pemrograman berorientasi objek (OOP) mengenai konsep pewarisan (Inheritance) pada bahasa Java.

## Struktur Class
*   **PerangkatElektronik** (Superclass): Menyimpan atribut umum seperti merk dan daya.
*   **Smartphone** (Subclass): Mewarisi PerangkatElektronik dengan tambahan atribut Sistem Operasi.
*   **Laptop** (Subclass): Mewarisi PerangkatElektronik dengan tambahan atribut GPU.

## Cara Menjalankan
1. Clone repository ini.
2. Buka folder di VS Code.
3. Jalankan file `Main.java`.
